# Android Equations App

This project is an Android application designed to solve and store mathematical equations.
The app allows users to compute equations, save results locally, and view previously solved equations.

## Features
- Solve mathematical equations
- Save equations and results using a local database
- View saved equations
- Multiple activities with a simple and modern UI

## Technologies
- Java
- Android SDK
- Room (local database)
- MVVM architecture

## How to run
1. Clone the repository
2. Open the project in Android Studio
3. Sync Gradle files
4. Run the app on an emulator or physical device
